Why does the frame grow when I click?

Opening this answer makes the page taller. The script in the page sees that and tells the parent, which sets the new height. Nothing in the parent knows about this accordion.

Does it shrink when I close it?

Yes. The height comes from the content, not from the frame, so a shorter page gets a shorter frame.

Does the parent page need any code for this?

Only the component. The accordion, the chat and the form on this site are ordinary pages that know nothing about embed-react.

What about pages on other sites?

Those load through a small proxy route on your server, which adds the same script. Without it the frame keeps its first height and scrolls.
